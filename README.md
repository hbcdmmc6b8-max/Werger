# Weapon Evolution

Mobile-friendly 3D arena shooter prototype.

## Features
- First-person 3D arena
- Enemy waves
- HP / XP / levels / kills
- 12 weapon mutations
- Visual weapon changes
- Mobile joystick, aim, fire and reload
- Desktop WASD + mouse
- Damage numbers
- Hidden combo: Explosive Rounds + Ricochet Core = CLUSTER RICOCHET
